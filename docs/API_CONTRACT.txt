HEALHER QUESTIONNAIRE GUIDANCE & PERSONALISATION API CONTRACT
=============================================================

1. OVERVIEW
-----------
This document specifies the contract for the Questionnaire Scoring and Optional AI Personalisation Layer (PHQ-9 and EPDS) in the HealHer backend.

The guidance system helps mothers receive supportive, evidence-based self-care suggestions following a perinatal screening.
The approved suggestions library in data/questionnaire_suggestions.json (plus data/library_overrides.json) is the ONLY source of suggestions.
The AI model may ONLY choose and order approved library items (Mode A), and optionally reword them into the user's language or simpler words (Mode B).
The model NEVER adds advice, facts, numbers, phone numbers, medicines, or medical content.
On any exception, timeout, 429, invalid JSON, or safety gating, the system falls back seamlessly to the deterministic non-AI result.


2. AUTHENTICATION & SECURITY
----------------------------
- Authentication Header:
  Production/Staging: Authorization: Bearer <supabase_jwt_token>
  Development: x-user-ref: <dev_user_identifier> (only if APP_ENV=development)
- Rate Limit: 20 requests per minute per user (enforced by user reference).
- Request Body Limit: 10 KB maximum.
- CORS: Restricted strictly to FRONTEND_ORIGIN.
- Privacy & Logging:
  Request bodies, prompts, and model outputs are NEVER logged.
  Only internal telemetry error codes (e.g. error_code=select_exception) are recorded.
  Tracing remains strictly disabled (LANGCHAIN_TRACING_V2=false, LANGSMITH_TRACING=false).

4. SAFETY GATING & DETERMINISTIC FALLBACK
-----------------------------------------
The AI model is NEVER invoked when any of the following conditions hold:
  1. safety_triggered is true (e.g. PHQ-9 Q9 > 0 or EPDS Q10 > 0)
  2. escalation level is "see_clinician_soon" or "see_clinician_urgent"
  3. No approved candidate suggestions exist for the band and stage
  4. GUIDANCE_AI_ENABLED is false in environment configuration
  5. APP_ENV is "forbidden"
In all these gated cases, the backend immediately returns the deterministic library result with personalised=false and mode="none".

Mandatory Clinical Rules:
  - Clinician Contact Item (SUG_CLINICIAN_CONTACT): In any result with escalation "see_clinician" or higher, the clinician contact recommendation is strictly pinned at position 0 (first item), regardless of model ordering.
  - Mixed Evidence Items (e.g. SUG_CALMING_PRACTICE): Practice recommendations graded with "mixed" evidence are strictly excluded from "moderate", "moderately_severe", and "severe" bands.
  - Verified Helplines Only: Helplines are strictly verified Indian national services (Tele-MANAS 14416, National Emergency 112, Women Helpline 181). Disallowed foreign helplines (1800-889-4357) and legacy numbers (102, 108) are prohibited.


5. MODEL PROMPT PRIVACY BOUNDARIES
----------------------------------
The model NEVER receives user free text, notes, names, emails, user IDs, or numerical scores.
The prompt contains ONLY 7 structural metadata fields:
  - instrument (phq9 | epds)
  - stage (prenatal | postnatal)
  - language (en | hi | bn | ta)
  - band_id (minimal | mild | moderate | moderately_severe | severe | well | possible_mild_depression | possible_depression)
  - escalation (routine | monitor | see_clinician | see_clinician_soon | see_clinician_urgent)
  - themes (filtered subset of 18 fixed tags)
  - candidates (list of candidate objects with id, category, English text only)


6. REWORDING VALIDATION RULES (Mode B)
--------------------------------------
When GUIDANCE_AI_REWORD=true, the model rewrites selected items. Every rewritten sentence undergoes strict code validation before display:
  - Length: At most 1.3 times the original English word count.
  - Digits: No new digits allowed unless identical to digits present in the original sentence.
  - Phone Numbers & URLs: No phone numbers or URLs permitted unless present in original.
  - Diagnostic & Clinical Words: None of the forbidden diagnostic terms (depression, depressed, severe, diagnosis, disorder, etc.) across en, hi, bn, ta.
  - Medication Words: None of the medication terms (tablet, medicine, antidepressant, SSRI, dose, etc.) across en, hi, bn, ta.
  - Language Script Check: Devanagari script for Hindi, Bengali script for Bengali, Tamil script for Tamil, Latin script for English.
Any item failing validation is discarded and replaced with approved library text in that language.

Analyzes mother's check-in note for tone, intensity, themes, and gentle reflection.
Selects theme-specific, tone-aware, stage-aware suggestions using deterministic code from data/sentiment_suggestions.json.
The AI model NEVER generates, rewrites, or invents suggestions; suggestions are strictly selected by code.

Request Headers:
  Content-Type: application/json
  Authorization: Bearer <supabase_jwt_token> (or x-user-ref in development)

Request Body:

  "language": "en",
  "stage": "postnatal"
}

Request Parameters:
  - note_text (string, required): Minimum 10 words or 50 characters (excluding spaces). Max 50 KB body.
  - language (string, optional, default "en"): "en", "hi", "bn", or "ta".
  - stage (string, optional, default "postnatal"): "prenatal" or "postnatal".

  - suggestions is strictly [] (empty array).

12. EDUCATIONAL VIDEO LIBRARY ROUTES
------------------------------------
General educational content. Non-diagnostic, does not trigger scoring, bands, or safety actions.

### A. GET /api/videos
Protected by Header: Authorization: Bearer <supabase_jwt_token> (or x-user-ref in dev mode).
Rate limit: 60/minute.

Query Parameters:
- audience (required): prenatal | postnatal | caregiver.
  Only returns videos whose catalogue entry includes this audience.
- language (optional, default: en): en | hi | bn | ta.
- trimester (optional): 1 | 2 | 3.
  If provided, videos matching this trimester are sorted first without hiding others.

Language Fallback Rule:
- If a video in the requested language exists on disk, it is served with fallback: false.
- Otherwise, English video is served with fallback: true, and the requested language's captions
  (.vtt) are attached if present.
- If neither the requested language nor English video exists on disk, the video is skipped.
- Titles and descriptions use the requested language if non-empty, otherwise English.

### B. GET /media/videos/{video_id}/{filename}
Public media endpoint (no Authorization header required so HTML5 video tags and mobile browsers work).
Zero user identifiers logged, no cookies, no analytics.

Supported extensions:
- .mp4 (Content-Type: video/mp4)
- .vtt (Content-Type: text/vtt, verified WEBVTT header)
- .jpg / .jpeg (Content-Type: image/jpeg)

Headers & Streaming:
- Cache-Control: public, max-age=3600
- Accept-Ranges: bytes
- Full request returns 200 OK with Content-Length.
- Range request (e.g. Range: bytes=0-1048575) returns 206 Partial Content with Content-Range
  (e.g. bytes 0-1048575/10056948) and Content-Length.
- Out of bounds or invalid Range returns 416 Range Not Satisfiable.
- Strict path traversal prevention: any unmanifested video_id or filename returns 404.

### C. POST /api/admin/videos/refresh
Protected by Header: x-admin-token: <ADMIN_TOKEN>
Rescans VIDEO_DIR, validates MP4 and VTT files, re-checks catalogue against forbidden words,
and updates in-memory manifest.
